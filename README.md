Requirements

- Node.js installed
- Visual Studio Code or another code editor
- Command Prompt or VS Code Terminal

Check your Node.js installation:

bash
node --version
npm --version


Running the Activities

1. Clone or download the repository.
2. Open the repository folder in Visual Studio Code.
3. Open the terminal.
4. Navigate to the activity folder you want to run.
5. Execute its JavaScript file using Node.js:

bash
node filename.js


Use the actual filename inside the selected activity folder.
